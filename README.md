# java-lotto-precourse

# 🧩 구현할 기능 목록

## 📥 입력

- 사용자에게 구입 금액을 입력받는다. (1000원 단위로) → 바로 출력

```
구입금액을 입력해 주세요.
8000
```

- 당첨 번호를 쉼표를 기준으로 입력받는다.

```
당첨 번호를 입력해 주세요.
1,2,3,4,5,6
```

- 보너스 번호를 입력받는다.

```
보너스 번호를 입력해 주세요.
7
```

## 🎲 로또

- 사용자가 입력한 금액만큼 랜덤으로 로또를 생성한다.
    - 오름차순으로 정렬해서 출력한다.
- 입력 받은 당첨 번호와 보너스 번호를 `WinningLotto`에 저장한다.
- 사용자가 구매한 로또와 `WinningLotto`를 비교해 해당하는 `LottoRanking`을 찾아낸다.
- 모든 `LottoRanking`을 저장한다.
- 최종적으로 수익률을 계산한다.

## 📤 출력

- 구매한 로또 개수만큼 로또 번호를 출력한다.

```
8개를 구매했습니다.
[8, 21, 23, 41, 42, 43]
[3, 5, 11, 16, 32, 38]
[7, 11, 16, 35, 36, 44]
[1, 8, 11, 31, 41, 42]
[13, 14, 16, 38, 42, 45]
[7, 11, 30, 40, 42, 43]
[2, 13, 22, 32, 38, 45]
[1, 3, 5, 14, 22, 45]
```

- 당첨 통계를 출력한다.

```
당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 62.5%입니다.
```

## ‼️ 예외

- 사용자가 구입 금액을 올바른 형식으로 입력하지 않았을 때 예외를 발생시킨다. -> `IllegalArgumentException`
- 사용자가 당첨 번호를 올바른 형식으로 입력하지 않았을 때 예외를 발생시킨다. -> `IllegalArgumentException`
- 사용자가 보너스 번호를 올바른 형식으로 입력하지 않았을 때 예외를 발생시킨다. -> `IllegalArgumentException`
- 사용자가 보너스 번호를 당첨 번호와 중복해서 입력한 경우 예외를 발생시킨다. -> `IllegalArgumentException`
